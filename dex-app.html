Features

Everything you need to run a smarter meeting

Dex is the only AI assistant built specifically for small business meetings — connecting your live conversation to your actual business data.

🎙️
Live Meeting Intelligence

Dex joins your Microsoft Teams call as a native bot, listens in real-time, and detects when someone asks a business question — no manual activation needed.

🔗
RAG-Powered Data Retrieval

The moment a question is detected, Dex uses Retrieval-Augmented Generation to fetch live data directly from your Xero or Shopify account via secure API calls.

⚙️
MCP Precision Calculations

Dex uses Model Context Protocol to run exact calculations — growth rates, runway days, average order value — so every figure spoken in the meeting is verified and precise.

How it works

From spoken question to live answer in under 2 seconds

Dex runs a 5-stage AI pipeline the moment a question is asked — completely invisible to participants.

1
ASR
Speech Recognition

Whisper ASR transcribes the meeting in real-time and detects question intent from natural conversation.

2
LLM
Intent Analysis

GPT-4 classifies the question — revenue, orders, cash flow — and determines which data source to query.

3
RAG
Live Data Fetch

Dex calls the Xero or Shopify API in real-time and retrieves the exact figures needed for the answer.

4
MCP
Precision Compute

Model Context Protocol runs calculations — growth percentages, cash runway, averages — with full accuracy.

5
Reply
Spoken Response

Dex delivers the answer as a voice reply in the Teams call and displays it as a card on all screens.
